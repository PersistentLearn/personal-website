# 温子扬个人网站：第 2 步

本项目用于学习网页开发、测试、发布和维护。当前是免安装依赖的静态网站。
本次修改先用于本地学习，尚未更新线上演示站。部分栏目仍为早期演示文案，正式发布前会核对。

## 文件分别负责什么

| 文件 | 职责 | 适合修改的内容 |
| --- | --- | --- |
| `dist/index.html` | 页面内容和结构 | 标题、简介、栏目、图片引用 |
| `dist/assets/css/style.css` | 页面外观 | 颜色、字号、布局、手机适配 |
| `dist/assets/js/main.js` | 页面交互 | 菜单展开与收起、项目分类筛选、回到顶部、滚动效果 |
| `dist/assets/images/wen-ziyang.jpg` | 头像资源 | 替换照片 |

## 在自己电脑上打开

1. 解压完整压缩包，保留文件夹结构。
2. 双击 `dist/index.html`，可以直接查看本版页面。
3. 当前无需运行 npm，也无需安装依赖。

只复制 HTML 文件会导致样式、脚本、照片无法加载，因为它们已拆到独立文件。
浏览器地址若以 `file:///` 开头，表示直接打开磁盘文件；这一步还没有启动 localhost 服务。
当前项目使用普通脚本，不使用模块导入或 fetch，因此支持这种直接打开方式。

若电脑已经安装 Python，也可以在项目根目录 `personal-site-step2` 的终端运行：

```bash
python -m http.server 5173 --bind 127.0.0.1 --directory dist
```

然后访问 `http://localhost:5173/`。`--directory dist` 指定网站目录，无需先进入 `dist`。
终端保持运行，按 Ctrl+C 停止。这里的 5173 是手动指定的端口，并不表示使用了 Vite。
如果没有 Python，先用双击方式完成本课；下一步根据电脑系统配置开发环境。

## 理解相对路径

HTML 中：

```html
<link rel="stylesheet" href="./assets/css/style.css">
<script src="./assets/js/main.js" defer></script>
<img src="./assets/images/wen-ziyang.jpg" alt="温子扬的个人证件照">
```

`./` 表示从当前 HTML 所在文件夹出发。
`defer` 让脚本在 HTML 解析完成后执行，菜单脚本才能找到页面按钮。
上线时，浏览器分别请求 HTML、CSS、JavaScript 和图片；它们都需要部署。

## 第一次 Vibe Coding 练习

用 Codex 打开解压后的项目文件夹，输入：

```text
请读取 README.md 并检查现有文件结构。
只修改 dist/assets/css/style.css，将主题强调色 --mint 改为 #8ab4ff。
保持文字、图片和布局不变，不增加依赖，不部署。
完成后告诉我修改位置，以及如何刷新浏览器验收。
```

验收：主按钮和强调色从绿色变为蓝色，头像、文字、布局与手机菜单保持正常。
这是“限定目标、指定范围、约束改动、约定验收”的一次小任务。
改完不喜欢可要求 Codex 只把 --mint 恢复为 #76d9b4。

## 关于 dist

目前直接维护 dist 中的文件，它是本课的可运行网页目录，没有构建步骤。
引入 Vite 后，会将源码移到根目录 / src，dist 再作为自动生成的部署产物。
